# CV Website: Syed Muhammad Abdullah
Responsive portfolio website built with HTML, CSS and JavaScript.

## Live website
https://abd1syed.github.io/cv-website/

## Features
- Responsive portfolio layout
- Animated hero section and interactive background
- Light/dark theme toggle
- Project filters and animated counters
- WhatsApp and email contact links

## Deployment
GitHub Pages serves this site from the `main` branch root. Enable it in Settings > Pages if it is not already enabled.
